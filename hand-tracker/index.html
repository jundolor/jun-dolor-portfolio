AI-powered Hand Tracker

The hand tracker maps a person's hand in the video into 21 landmark points, which are used to draw circles and lines that follow the person's hand movements.

The Python code uses MediaPipe's pretrained Machine Learning model, together with the following resources:

  • OpenCV
  • NumPy
